2단계: 설정창이 잠겨서 안 눌릴 때 (PowerShell 명령어)

설정 창이 회색 자물쇠로 막혀있다면 아래 버튼을 눌러 명령어를 복사하세요.



▶ 관리자 권한 PowerShell 실행법

  1. 윈도우 화면 왼쪽 아래 시작 버튼을 마우스 오른쪽 클릭합니다.
  2. 메뉴에서 [터미널(관리자)] 또는 [Windows PowerShell(관리자)]를 켭니다.
  3. 창이 뜨면 위에 복사한 명령어를 붙여넣고 엔터(Enter)를 칩니다.
  4. 크롬이 꺼지면 다시 켜서 1단계를 다시 진행하세요.
