2단계: 설정창이 잠겨서 안 눌릴 때 (PowerShell 명령어)

회색 자물쇠 상태로 막혀있다면 아래 버튼을 눌러 잠금 해제 명령어를 복사하세요.



▶ 관리자 권한 PowerShell 실행하는 법

  1. 윈도우 화면 왼쪽 맨 아래 시작 버튼을 마우스 오른쪽 클릭합니다.
  2. 메뉴에서 [터미널(관리자)] 또는 [Windows PowerShell(관리자)]를 실행합니다.
  3. 창이 열리면 위에 복사한 명령어를 붙여넣고 엔터(Enter)를 칩니다.
  4. 크롬이 꺼지면 다시 켜서 1단계를 마저 진행하시면 됩니다.
